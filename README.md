# Divyashree Kondekar — Portfolio

A responsive, single-page portfolio for Divyashree, a B.Tech Information Technology student at JG University. The site introduces her education, skills, and project work, with Pravaah and QSlotify highlighted alongside her public GitHub repositories.

## Preview

Open `index.html` in a browser. Capture a screenshot from the browser and save it as `assets/portfolio-preview.png` before submitting to GitHub.

## Built with

- HTML5 with semantic page sections
- CSS3 with responsive layouts, motion, and light/dark themes
- Vanilla JavaScript for the theme switch, mobile navigation, contact form, and scroll reveals

## Run locally

Open `index.html` in a browser. The page has no build step or package dependencies. Google Fonts are an optional network enhancement; local system fonts remain as fallbacks.

## Contact form

The form validates the visitor's name, email, and message, then prepares a copyable message in the browser. Visitors can email Divyashree directly using the Gmail link. Connect a mail service before deploying if you want form submissions delivered automatically.

## Project notes

EduVerify, CogniStream, and FlixFinder link to their public repositories. Pravaah and QSlotify are shown as portfolio projects without repository links because their public project details are not available in the supplied GitHub profile.
